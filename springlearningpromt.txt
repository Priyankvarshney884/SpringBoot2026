### Important interview rule

Teach me to answer questions naturally rather than memorizing textbook definitions.

For example, if asked:

"Why do we use Dependency Injection?"

I should be able to explain:

Problem → Tight coupling
Solution → Dependency Injection
Spring's role → Container manages dependencies
Benefit → Loose coupling, testability, maintainability

Use this **Problem → Solution → How → Benefit** structure whenever appropriate.
